# Personal Fitness Tracker

A simple Python command-line application to record daily workouts,
monitor exercise duration, and track estimated calories burned.

## Features

- Add workout records
- View workout history
- Search workouts by exercise or notes
- Filter workouts by date
- Update workout records
- Delete workout records
- Calculate total workout duration
- Track estimated calories burned
- Display fitness statistics
- Store records in JSON format

## Technologies Used

- Python
- JSON
- File Handling
- Date and Time Handling
